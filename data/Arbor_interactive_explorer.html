Quantitative Structure Forest

QSM: a Quantitative Structure Model is a three-dimensional reconstruction of one tree, explicitly describing stems, branches, radii, topology and woody volume.

QSF: a Quantitative Structure Forest extends this concept to the stand level by combining all individual QSMs in one coherent 3D forest representation. This links tree architecture with stand structure, competition, biomass distribution and canopy organisation.

Instead of drawing every QSM simultaneously, the explorer uses the QSF tree map as an index. Click a reconstructed tree to load its complete individual QSM topology in the 3D viewer below. This keeps large trees detailed while avoiding an overloaded forest-wide WebGL scene.

QSF semantic reclassification

Experimental Arbor feature: qsf_segment_semantic() uses the reconstructed QSF to refine the wood / foliage separation. Arbor’s initial semantic segmentation is designed primarily to support QSM reconstruction, so this QSF-based post-processing is more appropriate for downstream analyses where the wood-foliage split itself matters.

The same sampled point indices are used before and after reclassification whenever the point count is unchanged, allowing the quantitative class-count and transition summaries below.

Interpretation notes

The QSM / QSF topology used in this explorer is interpreted as follows:

  • axis_ID = 1 = main stem
  • branch_order = 2 = primary branches
  • branch_order = 3 = secondary branches
  • branch_order >= 4 = tertiary and higher-order branches

The interactive report is intended for forest-structure exploration, QSM quality control and identification of structurally unusual or prominent trees. For scientific stand-level reporting, use the actual plot boundary for per-hectare calculations.
